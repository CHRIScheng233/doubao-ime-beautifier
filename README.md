# 豆包输入法美化器 · DoubaoIME Beautifier

本项目用于定制 Windows 任务栏上豆包输入法（PC 版）的输入状态显示：将「中 / 英 / A」输入状态指示字形由黑色改为白色，并将输入法头像由豆包默认图标替换为系统键盘图标。

项目提供三个相互独立、可单独执行的批处理脚本，无需安装，双击即可运行，并支持随时还原。

## 功能概述

Windows 任务栏的语言栏会为当前输入法绘制两类元素：

1. **输入法头像**：状态字形旁的小图标；
2. **输入状态字形**：中 / 英 / A 三个字符。

豆包输入法默认使用品牌色圆形头像，且状态字形为黑色，在深色任务栏下对比度较低、辨识困难。本项目针对上述两类元素分别提供解决方案。

| 脚本 | 功能 | 修改对象 |
| --- | --- | --- |
| `doubao-ime-replace-icon.bat` | 将豆包默认头像替换为系统键盘图标 | 注册表 CTF 图标项（64 位与 32 位两个视图） |
| `doubao-ime-whiten-indicator.bat` | 将「中 / 英 / A」指示字形由黑色改为白色 | `tsf-oime-core.dll`（x64 与 x86）各修改 3 字节 |
| `doubao-ime-restore-all.bat` | 还原为原厂外观 | 恢复 DLL 备份与原厂图标注册表值 |

三个脚本功能相互独立，可按需单独使用。

## 实现原理

任务栏输入状态由两条互不影响的渲染路径分别产生：

- **头像**：由系统从注册表中登记的图标文件读取，修改注册表即可变更；
- **字形**：由输入法自身的动态库 `tsf-oime-core.dll` 绘制，颜色分支以指令形式内嵌于其中，需通过修改该动态库实现。

因此本项目分别采用注册表修改与二进制补丁两种方式实现。

### 一、头像替换 — `doubao-ime-replace-icon.bat`

输入法头像由该输入法 TSF 语言配置中的图标字段决定：

```
HKLM\SOFTWARE\Microsoft\CTF\TIP\<输入法 CLSID>\LanguageProfile\0x00000804\<Profile GUID>
    IconFile   (REG_SZ)     图标来源（.ico / .dll / .exe）
    IconIndex  (REG_DWORD)  图标序号
```

豆包输入法实测值：CLSID 为 `{9D2B2E2B-…}`，语言标识 `0x00000804`，原厂指向 `C:\Windows\System32\tsf-oime.dll`，`IconIndex` 为 0。

实现方式：

- 将脚本内嵌的多尺寸 ICO 文件（16 / 20 / 24 / 32 / 48 px，覆盖不同 DPI 缩放）释放到本地目录；
- 将 `IconFile` 与 `IconIndex` 指向该图标文件；
- 同时修改 `SOFTWARE\\…` 与 `SOFTWARE\WOW6432Node\…` 两个视图，避免读取到旧值；
- 修改后需重启 `explorer.exe` 生效（脚本默认自动执行）；
- 修改前导出原厂值备份，可随时还原。

### 二、指示字形改白 — `doubao-ime-whiten-indicator.bat`

中 / 英 / A 三个字形的位图以 RCDATA 资源形式内嵌于 `tsf-oime-core.dll`，黑色与白色各一套：

| 资源 ID | 字形 | 颜色 |
| --- | --- | --- |
| 101 / 102 / 103 | 中 / 英 / A | 黑色 |
| 106 / 107 / 108 | 中 / 英 / A | 白色 |

资源 ID 对应关系为：白色 ID = 黑色 ID + 5。

动态库中存在一个分发函数，依据系统主题标志，通过条件移动指令 `cmovne ecx, edx` 决定采用黑色或白色资源组。本脚本将该条件选择改为无条件获取白色资源组（`cmovne ecx,edx` 改为 `mov ecx,edx` 与 `nop`，指令长度不变），每个架构仅修改 3 字节，不涉及重定位。

定位方式采用锚点匹配而非固定偏移：脚本检索字节序列 `B9 65 00 00 00 BA 6A 00 00 00`（对应 `mov ecx,101` 与 `mov edx,106`），其后 24 字节内的 `0F 45 CA` 即为唯一分发点。当锚点或字节不匹配（例如豆包更新导致偏移变化）时，脚本不执行任何写入并安全退出。

x64 与 x86 两份动态库均需修改：64 位宿主程序加载 `versions\<版本>\tsf-oime-core.dll`，32 位宿主程序加载 `versions\<版本>\x86\` 下的副本，脚本自动识别并分别处理。

修改后的代码仅在补丁写入之后启动的进程中生效。脚本默认在完成后重启 `explorer.exe`；若个别前台程序仍显示旧颜色，重启该程序或重启系统即可。

### 三、一键还原 — `doubao-ime-restore-all.bat`

- 从备份中逐字节还原被修改的动态库，并恢复原厂头像注册表值；
- 支持单独还原其中一项：`/dll` 仅还原字形，`/icon` 仅还原头像；
- 还原前后均校验字节，避免写入损坏的动态库。

### 与 TranslucentTB 的兼容性

在使用 TranslucentTB 等工具将任务栏设为透明或亚克力效果时，默认的黑色「中 / 英 / A」字形辨识度进一步下降。本项目可作为补充：

- 改白后，任务栏无论为纯色、透明或亚克力，三种状态字形均清晰可辨；
- 补丁仅修改 `tsf-oime-core.dll` 中颜色资源的选择逻辑（3 字节），不涉及任务栏本身的绘制，因此不会与 TranslucentTB 的透明、模糊或颜色效果冲突；
- 两个工具各自独立，可同时使用。

## 使用方法

1. 从 Releases 页面下载所需的 `.bat` 文件，存放于任意目录；
2. **以管理员身份**运行（需修改 `HKLM` 注册表与程序文件）；
3. 如需先查看将要执行的修改，可运行只读预览：

   ```bat
   doubao-ime-replace-icon.bat --check
   doubao-ime-whiten-indicator.bat --check
   ```

4. 如需还原，运行 `doubao-ime-restore-all.bat`。

### 参数说明

| 参数 | 说明 |
| --- | --- |
| `--check` | 只读预览，不执行任何写入，不重启 explorer |
| `--no-restart` | 执行修改，但不自动重启 explorer |
| `--dir <目录>` | 手动指定豆包输入法安装目录（通常无需使用） |

## 兼容性

- 豆包输入法 PC 版 v0.9.0.0 已实测通过（x64 与 x86 均已验证）；
- 支持 Windows 10 / 11；
- 默认安装目录为 `C:\Program Files\DoubaoIME\`，脚本通过通配符自动识别实际版本目录。

## 常见问题

**问：修改后「英」字仍为黑色？**<br>答：通常是由于相关程序在补丁写入之前已经启动，内存中仍为旧代码，重启该程序或重启系统即可。

**问：豆包更新后修改失效？**<br>答：更新会覆盖动态库或更换版本目录，重新运行对应脚本即可。

**问：是否影响输入法功能？**<br>答：不影响。脚本仅修改颜色资源的选择逻辑与头像指向的文件，不涉及输入、候选词与切换逻辑。

**问：是否可以撤销？**<br>答：可以。每次修改前均会自动备份原文件，运行 `doubao-ime-restore-all.bat` 即可完整还原。
